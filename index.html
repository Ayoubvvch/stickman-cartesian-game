Movement & Math Controls
⌨️ Keyboard
  • ← → or A D : Walk along x-axis
  • Shift + Move : Sprint (or fast climb / descend)
  • Space or W / ↑ : Jump (double jump)
  • Q (or W/↑ at x = 0) : Climb y-axis
  • G : Free Fall — ↓ Dive / ↑ Air Brake
  • f(x) Lab : Toggle curves (OFF by default) · S carve · S+Space drop
  • Trials Mode : Calculus challenges (B Lock critical/inflection point)
  • Z : Dance (1 Purple · 2 Disco · 3 Honored One · M Mute)
  • S / ↓ : Crouch/Slide · E/K : Dash · F : Flip · R : Reset
🎮 Controller
  • Left Stick : Analog walk / run · push up at x = 0 to climb
  • D-Pad + RT/LT/LB : Walk, sprint, or fast climb
  • A / ✕ : Jump (press again for double jump)
  • B / ○ : Crouch / Slide · or release climb
  • X / □ or RB : Dash
  • Y / △ : Dance on ground / Flip in mid-air
  • Start / Options : Reset to O(0,0)
